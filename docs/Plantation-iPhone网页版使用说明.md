# Plantation iPhone 网页版使用说明

## 一、添加到主屏幕

请使用 Safari，不要从微信、QQ 或其他 App 的内置浏览器直接安装。

```text
Safari 打开 Plantation
→ 分享
→ 添加到主屏幕
→ 开启“作为网页 App 打开”
→ 添加
```

如果“分享”菜单里没有“添加到主屏幕”，向下滑并点“编辑操作”，将它加入。安装完成后，主屏幕会出现 Plantation 图标。以后尽量固定从这个图标进入。

首次访问必须联网。成功打开并等待片刻后，应用外壳会被缓存；短时间断网时仍可查看本机已经保存的计划。GitHub Pages 或网络不可用时，未被缓存的新文件无法加载。

## 二、第一次导入计划

1. 先把仓库外单独收到的真实计划 JSON 保存到 iPhone 的“文件”App。
2. 从主屏幕打开 Plantation。
3. 首页点“导入学期计划”；已有计划时，也可以到“提醒”页点同名按钮。
4. 在文件选择器中找到 JSON 并选择。
5. 导入成功后回到“日程”，检查日期、周次、课程、老师、教室和备注。

“载入匿名示例计划”只用于试用界面，里面的课程、教师和教室都是示例值。她的真实课表应通过“文件”导入，不能提交到公开仓库。

附带计划的校历假设为：2026-09-07 是第 1 周周一，2026-09-28 至 10-04 为秋假且不计教学周，学期到 2027-01-17。请与学校校历核对。

## 三、查看与打卡

- “日程”：查看某天安排。点日期可跳转，左右箭头切换一天。
- “本周”：查看周一至周日；点日期进入当天。
- 点计划卡片：查看完整备注、地点和时间。
- 点卡片右侧 `+`：完成打卡；变成 `✓` 后再次点击可取消。
- 未来日期不能提前打卡，过去可以补记。
- “休息”不计入完成率。
- “打卡”页显示今日完成率、连续行动、累计完成和历史快照。

修改或删除课表不会删除历史打卡。历史记录保存打卡时的日期、名称和类型快照。

## 四、添加、修改与删除计划

在“日程”或“本周”点“添加”：

- **临时新增**：只在所选日期出现。
- **永久新增**：从所选日期起按每周、单教学周或双教学周重复，直到指定日期。
- **自定义类型**：点击“类型”后可直接输入“社团、兼职、值班、约会”等任意文字，也可以选择原有常用类型。保存后会成为这台设备上的常用选项，并出现在日历导出筛选中。

点已有项目，再点“修改计划 / 备注”：

- **临时修改**：只修改这一天，包括备注。
- **永久修改**：修改整个重复系列，包括这个系列在日程中的全部日期。

在修改页面点“删除计划”：

- **临时删除**：只隐藏这一天。
- **永久删除**：删除整个重复系列；已经留下的历史打卡仍保留。

临时新增本身不是重复系列，因此只能修改或删除这一次。发生时间重叠时，Plantation 会先提示，由你决定是否保留。

所有修改只影响 Plantation 本机数据，不会自动修改已经导入 iPhone 系统日历的事件。

## 五、导出 iPhone 日历

1. 打开底部“提醒”。
2. 设置“导出时携带提醒”开关。
3. 选择导出范围：7 天、30 天或到学期末。
4. 选择要包含的类型；默认不包含休息。
5. 点“导出 iPhone 日历 .ics”。
6. 系统显示日历预览和“添加全部”时，选择目标日历并添加。

建议先在系统日历中创建一个单独的 `Plantation` 日历，然后把事件放进去。这样整批替换更清楚。

如果 iPhone 只把 ICS 下载到“文件”而没有显示“添加全部”，可以在 Mac 上操作：

1. Mac 与 iPhone 登录同一个 Apple Account，并开启 iCloud 日历。
2. Mac 打开“日历”，新建一个 `Plantation` iCloud 日历。
3. 选择“文件 → 导入”，打开 ICS，目标选择新建的 Plantation 日历。
4. 等待 iCloud 同步到 iPhone。

请牢记：

> Plantation 内的提醒开关仅控制后续导出的日历内容，不会自动修改已经导入到 iPhone 系统日历中的事件，也不等于系统闹钟。

系统通知会受“日历”通知权限、静音模式、专注模式和系统设置影响。建议先导出一项近期计划做真实提醒测试。

计划变更后，可手动修改对应系统日历事件；需要整批重导时，先确认专用 Plantation 日历中没有其他要保留的内容，再删除旧事件或旧专用日历，之后重新导入。不要把同一批 ICS 反复叠加。仅隐藏日历不等于关闭提醒。

## 六、备份

1. 打开“提醒”。
2. 点“导出完整备份”。
3. 将 JSON 保存到 iPhone“文件”、iCloud Drive 或自己信任的位置。

完整备份包含：

- 当前学期和原始计划
- 永久修改
- 单日修改与临时新增/删除
- 打卡历史
- 提醒设置
- 所有备注

建议每周一次，以及大批修改、清理 Safari 数据、升级系统或换机之前各备份一次。备份可能含私人课表与备注，不要上传到公开 GitHub 仓库或公开群聊。

## 七、恢复

1. 打开“提醒”。
2. 点“恢复完整备份”。
3. 选择以前导出的完整备份 JSON。
4. 阅读替换提示并确认。

恢复会替换当前的全部本机数据。导入前若当前记录仍有用，应先导出一份新备份。无效、损坏或超过 20 MB 的文件会被拒绝，当前数据不会被覆盖。

“导入学期计划”和“恢复完整备份”不同：前者更换计划结构，但保留当前历史打卡与提醒设置；后者完整还原备份中的所有层。

## 八、更换手机

旧手机：

1. 从“提醒”页导出完整备份。
2. 确认文件确实存在并能分享或复制。

新手机：

1. 用 Safari 打开同一个 Plantation GitHub Pages 地址。
2. 添加到主屏幕。
3. 从主屏幕启动。
4. 选择“恢复完整备份”，导入旧手机的 JSON。
5. 检查几天日程和历史打卡。

iCloud 的 Safari 同步不等于 Plantation 数据备份，不要假设记录会自动迁移。

## 九、清除 Safari 网站数据会发生什么

Plantation 使用 IndexedDB 保存数据，必要时回退到 localStorage。以下操作可能删除或隔离记录：

- “设置 → Safari”中清除历史记录与网站数据
- 删除网站数据或针对 GitHub Pages 域名清理
- 长期不使用后系统清理网站存储
- 删除主屏幕网页 App
- 改用不同域名、不同仓库路径或不同浏览器入口
- 使用无痕浏览

丢失后只有以前导出的完整备份可以可靠恢复。重新部署相同源码不会找回已清除的本机数据。

## 十、版本更新与离线

作者发布新版本后，页面顶部会出现“Plantation 有新版本”。点“点击刷新”后切换到新版。刷新只更新公开应用文件，不会主动清空 IndexedDB 数据。

离线能力要在至少一次成功联网访问后才生效。直接从“文件”App 打开 `index.html` 可以查看和使用大部分功能，但不能注册 Service Worker，也不能作为可靠的 iPhone PWA 安装方式。日常使用应以 HTTPS GitHub Pages 地址为准。
